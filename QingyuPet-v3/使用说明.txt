青语 3.0 · 会回应你的桌面伙伴

启动
完整解压后双击 QingyuPet.exe。请保留旁边的 voice 文件夹。
适用于 Windows 10/11 x64 和 .NET Framework 4.8，不需要安装 Python 或开发工具。
本机桌面“青语桌宠”快捷方式已更新到新版，2.0 作为备份保留。

这次的变化
• 语音改为本地模型常驻：启动时提前加载，后续不再每句话重载模型。
• AI 文字流式显示，按句准备与播放声音；准备下一句时可以继续播放上一句。
• 开心、害羞、温柔、惊讶等语境会调整语速与轻微音高，支持单独关闭。
• 聊天会触发表情与动作，例如分享喜事时开心、被夸时害羞、难过时温柔回应。
• 保留原初青语，增加墨玉旗袍（盘发）和霓光赛博（短发）两套差异较大的形象。
• 专注计时已从新版界面、菜单和运行逻辑移除。

基本操作
按住角色拖动，松开保存位置。双击角色或点击名字，打开主界面。
角色上滚动滚轮：调整大小；右键：互动、外观换装、收起、复位与退出。
底部“停止动作 / 声音”同时取消当前回复、语音和动作。
再次运行 EXE 或双击系统托盘图标，可以召回现有角色。
面板右上角 × 或 Esc 关闭面板，桌宠继续运行。

外观与换装
打开“外观”，点击三张卡片切换形象。原先生成的紫色针织和酒红晚装稿已弃用。
大小范围 45%–165%，也有“缩小”“放大”“恢复 90%”按钮。
若窗口超出屏幕，显示大小会自动适配可见范围。
可调整透明度 55%–100%、置顶、身体动作；服装及外观设置会保存。
三套形象均有自然眨眼和说话嘴部开合；仍是分层二维动画，不是 Live2D 模型。

DeepSeek 连接
本机检测到原设置使用 DeepSeek-V4-Pro-0813，这不是可用的 API 模型 ID。
新版会把官方 DeepSeek 地址下该显示名称纠正为 deepseek-v4-pro，保留原 Key。
已实际读取账号模型列表，并用新版 C# 代码完成简短流式回复测试。

重新配置时：
1. 在“AI 聊天”点击“配置接口 / 读取可用模型”，直接跳到连接设置。
2. DeepSeek 地址填 https://api.deepseek.com。
3. 填写 API Key，点击“读取可用模型”，从返回列表中选择模型，再保存。
   本次检测返回 deepseek-flash 和 deepseek-v4-pro；以你账号实际列表为准。
4. 点击“测试连接”，或切回聊天输入文字。Enter 发送，Shift+Enter 换行。
模型名称不能填写网页标题、显示名称或任意版本号。
其他服务可填写其 OpenAI 兼容 Chat Completions 基础地址或完整接口地址。
新版使用 HTTPS/TLS 1.2，错误提示会区分密钥权限、余额、限流、地址和模型问题。
DeepSeek 的闲聊请求默认关闭深度思考，减少等待。

聊天与动作
AI 回复附带的情绪和动作标记会被隐藏，并只从本程序动作名单中选择。
不会执行模型给出的代码或任意桌面命令。没有有效标记时，按语境做基础回应。
“语音 / 连接”可以关闭“AI 聊天联动表情与动作”。
语音开关关闭时仍能文字聊天和做动作；“安静陪伴”停止动作、语音和自然眨眼。
聊天保留最近最多 6 轮成功对话作为上下文；清空对话、换接口/模型或退出会清空。
对话文字不另存历史文件，但本地朗读音频会进入缓存。

离线语音与速度
继续使用 MeloTTS 中文模型，通过 sherpa-onnx 原生 C API 在本机常驻运行。
本机测试：首次加载加短句合成约 4.15 秒；常驻后短句约 0.98–1.26 秒。
实际两句流水播放测试，首段口型运动约在 1.24 秒开始。具体随文本及电脑负载变化。
这些数字是本地语音测试，不包含 AI 服务思考和网络时间。
“语音 / 连接”可调音量、语速、情绪语调，或切换系统中文女声备用。
情绪语调是轻微语速/音高与文字节奏调整，不是训练了原生情感控制的专用声音模型。
新回复、停止、收起、退出都会结束当前播放。长回答最多朗读前约 480 字。
缓存上限 160 个 WAV / 128 MB，可在连接页底部清除。
没有使用联网语音服务，没有麦克风录音或实时语音通话。

数据与备份
配置：%LOCALAPPDATA%/QingyuPet/settings.json
声音缓存：%LOCALAPPDATA%/QingyuPet/voice-cache
异常日志：%LOCALAPPDATA%/QingyuPet/error.log（仅发生异常时）
API Key 由 Windows 当前用户 DPAPI 加密，不在源码或便携包中。
换 Windows 账号需要重新填写 Key。网络请求只发往你设置的聊天接口；费用按服务商规则。
读取模型列表会访问接口，程序启动不会自动发送 AI 聊天请求。
退出程序后可删除便携文件夹和快捷方式；按需清理设置和缓存。没有开机自启注册。

源码运行
解压源码，双击 build.cmd，再运行 bin/QingyuPet.exe。
把便携包 voice 文件夹放到源码 bin 下；或用 Python 3.12+ 运行 download-voice.py。
编译使用 Windows 自带的 Framework C# 编译器，目标 x64。
源码包含当前依赖对应的配置结构和来源许可，详见 README.md 及 THIRD-PARTY-NOTICES.md。
